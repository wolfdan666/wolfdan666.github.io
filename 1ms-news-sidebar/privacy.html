1ms News · 实时新闻侧栏

隐私政策

生效日期 2026 年 11 月 18 日

本扩展在 Chrome 侧栏展示 1ms.news 新闻，并根据新闻中的币种打开你选择的市场。首次开启或从旧版更新时，侧栏会先说明数据用途。点击「同意并开启侧栏」后开始连接服务和识别交易页。

设备上处理的信息

交易所标签页与页面内容
为显示当前市场、复用已打开的交易页，扩展查询当前窗口匹配 Binance、Hyperliquid 的标签页，使用地址、活动状态和最近使用时间。点击币种后，扩展可在交易页读取当前市场标题、交易对、链接及路由状态。币安现货有时需要暂用行情搜索框，切换完成后恢复原搜索词。这些标签页信息和页面内容在本机处理。
新闻和阅读偏好
最近的新闻和补漏游标保存在 Chrome 的会话存储中，浏览器结束会话后清除。币种目录、主题、筛选条件和启用选择存放在扩展本地存储中。新闻搜索词用于本地筛选。
可选的个人新闻 API key
你可以使用公共额度，也可以在设置中输入自己的 1ms.news API key。扩展用 AES-GCM 加密个人 key，将密文存入本地扩展设置。用于解密的密钥保存在扩展自己的 IndexedDB 中，解密后的个人 key 用于本次连接。旧版设置中保存的个人 key 在更新后首次启用时迁移。

哪些服务会收到请求

1ms.news 的 api.1ms.news 接收新闻列表、分页、补漏和实时订阅请求。填写个人 key 后，扩展通过 HTTPS 请求头或 WSS 认证消息将其发送给该服务。使用公共额度时采用公共认证方式。

Binance 和 Hyperliquid 的目录接口 fapi.binance.com、api.binance.com 和 api.hyperliquid.xyz 接收公开市场目录请求。点击币种会在所选交易所网站打开相应市场。点击新闻标题或原文会访问 1ms.news 或该条新闻所标示的来源网站。

上述网站与接口会收到建立网络连接所需的 IP 地址及常规请求信息。打开网页时，浏览器按你在该网站已有的设置和登录状态访问；该网站按其自身政策处理访问。个人新闻 key 仅供 1ms.news 认证。

使用范围

发布者仅为新闻阅读和市场导航功能处理上述信息。扩展不设发布者数据中转服务，不收集钱包、持仓或订单，不出售用户数据，也不将数据用于广告、信用评估或借贷。通过 Chrome API 获取的信息遵守 Chrome Web Store 用户数据政策，包括有限使用（Limited Use）要求。

查看、更改和删除

打开侧栏设置可更改主题和个人 key。清空 key 后点击「保存设置」，会删除本机保存的凭据并重新使用公共额度。如需撤销 key 本身，请联系签发方 1ms.news。关闭所有侧栏会停止实时连接。卸载扩展会删除其本机设置、缓存和密钥材料。

联系发布者

隐私或数据处理问题可通过本扩展 Chrome 应用商店详情页「开发者」栏列出的联系邮箱反馈。请勿在反馈中附上个人 API key。
